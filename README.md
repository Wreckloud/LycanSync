# LycanSync

LycanSync 是给朋友或小队使用的 Windows 语音与多人屏幕共享软件。几个人可以一边语音，一边各自共享游戏画面。支持多个多人群聊，可以发消息、图片和文件。

客户端目前处于试用阶段，提供 Windows x64 安装包。人人都可以自己架设服务器，邀请朋友分享自己的画面和音频。

## 和朋友一起用

如果朋友已经开服，先请服主发给你一个**服务器邀请链接**。有了邀请，在 Windows 上按这四步走。

1. 用浏览器打开邀请链接，点「下载 Windows 应用」并安装。已经装过的可以跳过这步。
2. 回到同一个邀请页面，点「打开应用」，在客户端确认加入。看到「连接并重启」时，按提示切到邀请对应的服务器。
3. 如果左侧还没有群组，点「＋」→「加入群聊」，填朋友给你的**群邀请码**。群主也可以直接把你加进群。
4. 双击群头像加入语音。想让朋友看你的画面，就点底部的共享图标，选游戏窗口、应用窗口或整块屏幕，再点「开始共享」。

服务器邀请负责创建账号，群邀请码负责进群。邀请过期时，请服主重新发一条。

## 常用功能

- **看多人共享**。几个人可以同时分享画面，观看时可切换聚焦、网格或弹出观看窗口。新共享默认只发画面，需要时再开启共享声音。
- **调整收听和麦克风**。可以静音、单独调成员音量，也能在设置里选择设备、开启按键说话或绑定快捷键。
- **聊天和传文件**。群聊保留历史消息。图片和常见视频可直接查看，文件可以保存到本机。
- **录制和即时回放**。共享时可以录下自己的画面。开启即时回放后，可以把刚才的一段保存到本机，再按需要剪辑或分享到群聊。

部分游戏的采集效果和共享声音取决于 Windows 版本与设备。遇到问题可在「设置 → 客户端 → 应用日志」填写发生时间和操作，点击「上传日志」发给当前服务器的服主，也可以导出到本机。服主在「服主管理 → 收到的日志」点击「接收日志」，桌面端会将 JSON 存入本机数据目录的 `exports/received`。

## 0.7.7 客户端更新

- 加入语音后，将指针移到自己的成员卡，点「播放伴奏」选择已打开的播放器或浏览器。朋友可以在你的卡片单独调节共享音量。点「暂停分享」会断开音源，下次可重新选择。
- 游戏和标准档均以 1080p60 为目标，稳定档为 720p30。默认网格中的画面声音为 10%，聚焦时该路恢复到 35%，其他画面静音。主动分享的伴奏可独立于画面聚焦播放。

## 0.7.6 客户端更新

- 群聊视频封面遇到临时故障时，会在卡片可见时自动再试，最多两次。期间可继续预览或下载视频。

## 0.7.5 客户端更新

- 共享中关闭声音后，若提示尚未确认停止，可以稍后在同一画面上重开声音。录制正在使用应用声音时，关闭共享声音仍会保留录制音源。
- 群聊里的视频封面临时加载失败时，可点文件卡片上的「重试视频封面」。仍可直接预览或下载文件。
- 启动检查得到更新结果后即可继续，诊断日志在后台写入。自动保存诊断报告减少了一次完整解析。
- 排查进房后麦克风准备慢时，可比较同一设备冷启动和再次开麦的两条 microphoneReady 记录。其中 firstCaptureWaitMs 表示等到首次采样的时间，captureToDeliveryMs 表示从首次采样到首包写入管道的时间。

## 自己开服

准备一台 Ubuntu x64 主机或虚拟机，并确保朋友能访问它。服主安装服务端、激活账号后，就可以创建群组和发邀请。 [服主首次安装手册](deploy/server/QUICKSTART.md) · [网络与部署说明](deploy/server/DEPLOY.md)
