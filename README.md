# LycanSync

面向 4–8 名熟人的 Windows 游戏语音、文字聊天和多人屏幕共享软件。

当前处于后端基础阶段。实时媒体采用自托管 LiveKit，业务控制面采用 Spring Boot，桌面客户端计划使用 Electron、React 和 TypeScript。

## 仓库原则

Git 只保存交付和部署真正需要的内容：

- 源码与测试；
- 数据库迁移；
- 构建文件和锁文件；
- Docker/部署定义；
- 不含密钥的配置模板；
- 面向部署者的 README 和许可证。

本地教学与规划笔记位于 `docs/`，由 `.gitignore` 排除，不进入交付仓库。真实密钥、IDE 状态、依赖目录、日志和构建产物同样不会提交。
