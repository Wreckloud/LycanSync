# LycanSync 服主首次安装手册

想和朋友一起用，先让朋友的电脑能访问你的服务器，再由你激活服主、发邀请、把朋友加进群组。服务器已经部署好的话，可以直接看第二步。

## 1. 把服务器跑起来

1. 准备一台 Ubuntu 24.04 x64 机器。自己的电脑里开一台 Ubuntu 虚拟机也可以。虚拟机和电脑都要在朋友使用时保持运行。
2. 装好 Docker Engine 和 Compose v2。运行 `docker compose version`，能看到版本号再继续。[Docker 官方安装步骤](https://docs.docker.com/engine/install/ubuntu/)
3. 把完整的服务端 ZIP 放到 Ubuntu，解压后进入解压目录，运行 `sudo python3 install.py`。
4. 只在自己的电脑上试用，就输入 Ubuntu 虚拟机的 IPv4 地址。要让异地朋友使用，先准备朋友可访问的服务地址，再按部署说明填域名和媒体入口。等终端出现「本机 API 已就绪」。[项目部署和网络要求](DEPLOY.md)

### 没有买云服务器怎么办

- **先自己试用。** VMware 默认 NAT 下，用宿主机访问虚拟机。这时需要让自己的 Windows 信任这台测试服务器的 CA，操作见部署说明的「仅内网 VMware 测试」。[项目内网测试说明](DEPLOY.md#3-仅内网-vmware-测试)
- **让几位异地朋友来用。** 可在 Ubuntu 虚拟机和朋友电脑上装 Tailscale，用它的设备共享只分享这台虚拟机。服主还要给 LycanSync 配置朋友能访问的 Tailscale 地址、可信 HTTPS 和对应的媒体入口，再从异地实测语音与共享。朋友先连 Tailscale，再打开 LycanSync 邀请。[设备共享](https://tailscale.com/docs/features/sharing) · [Tailscale HTTPS](https://tailscale.com/docs/how-to/set-up-https-certificates)
- **让朋友直接打开链接。** 如果家里有可用的公网入口，可以继续用家里的虚拟机，在路由器和 VMware 上配置对应转发，再使用域名和可信 HTTPS。没有可用公网入口时，单靠把家里的虚拟机地址发给朋友无法连通。[项目端口要求](DEPLOY.md#1-准备地址和网络) · [VMware 网络模式](https://knowledge.broadcom.com/external/article?legacyId=1006480)

外地朋友能打开邀请网页后，还要实测一次双方讲话和共享。网页能打开，只说明网页通了，语音和画面还要能到达媒体端口。

### 使用已经申请的 QQ 登录应用

客户端连接地址、服务器对外地址和 QQ 回调地址需要使用同一个 HTTPS 域名。例如客户端连接 `https://voice.example.com`，QQ 互联登记的回调和「服主管理 → 服务器配置 → 配置 QQ 登录」里的回调都填 `https://voice.example.com/api/auth/qq/callback`。这个域名的 HTTPS 入口必须能把授权回调送到发起登录的这台服务器。如果客户端仍连接内网 IP，应用会拒绝打开另一个域名上的授权地址。

保留原账号登录，从「账号设置 → 绑定 QQ」完成授权。下次就可以用 QQ 登录同一个账号。只测试异地联机时，可以先用一次性邀请验证，QQ 登录可单独接入。[QQ 配置与账号说明](DEPLOY.md#2-配置并启动)

## 2. 激活你自己的服主账号

1. 在 Ubuntu 终端进入刚才的解压目录，运行下面的命令。终端输出的链接只给你自己用。

   ```bash
   sudo docker compose exec -T api cat /var/bootstrap/admin-activation.txt
   ```

2. 在你的 Windows 浏览器打开链接。网页应显示「服主激活」和「链接有效」。内网测试弹出证书警告时，先按[内网测试说明](DEPLOY.md#3-仅内网-vmware-测试)核对你这台服务器自己的 CA。双击证书，点「安装证书 → 当前用户 → 将所有证书放入下列存储 → 浏览」，明确选「受信任的根证书颁发机构」。如果放进「中级证书颁发机构」，浏览器仍会提示不信任。
3. 点「下载 Windows 应用」，运行下载好的安装程序。**保留激活网页。** 已经安装客户端的，可以跳过下载和安装。
4. 回到刚才的激活网页，点「打开应用」。如果客户端出现「连接并重启」，先点它切到你的服务器。填两遍恢复密码，再点「确认激活」。恢复密码用于以后找回你的服主账号，至少 6 位。
5. 填写昵称或跳过资料设置，按界面提示进入应用。你能在设置里看到「服主管理」，就可以发邀请了。

## 3. 邀请朋友进服务器，再拉进群

1. 打开「设置 → 服主管理 → 邀请新朋友」。复制邀请链接，发给一位朋友。每条链接只能成功使用一次，最长有效 3 天。邀请下一位时点「生成新的邀请链接」。
2. 在左侧群组列表点「＋」创建群组。再点群组名称打开菜单，选「邀请成员」并复制群组邀请码。朋友接受服务器邀请后，点左侧「＋」，再点右上角「加入群聊」，输入这个码并点「加入群组」。你也可以在「管理成员」里直接添加已经加入服务器的朋友。
3. 朋友看到群组后，在里面发一条消息。你能收到，就完成了从安装到进群的检查。双击群组头像可以加入语音。

## 可以直接发给朋友

> 在 Windows 上打开我发你的邀请链接，点「下载 Windows 应用」。装完回到同一个网页，点「打开应用」，在客户端确认加入。进入应用后，点左侧「＋」→ 右上角「加入群聊」，输入我发你的群邀请码。

## 卡住时看这里

- **下载了安装包，打开应用却没有邀请。** 回到原来的邀请网页点「打开应用」。安装包本身只负责安装。
- **0.6.7 点「连接并重启」后显示 `An object could not be cloned`。** 在客户端点「取消 → 更多」，把「服务器地址」改成邀请网页的地址（只填 `https://` 加主机名或 IP），点「保存并重启」。再回到原网页点「打开应用」，按提示激活或加入。
- **朋友打不开链接。** 先检查他能否访问你的服务器。异地朋友用 Tailscale 时，要先连接并接受设备共享。家里虚拟机的 NAT 地址通常只有宿主机等能直接访问。
- **朋友已经加入，左边却看不到群。** 再发给他群邀请码，或者在群管理里添加他。
- **已经在群里，再输入群邀请码。** 应用会打开原群聊，成员资格和语音状态保持原样。
- **发送图片时提示无法优化。** 勾选这张图片下方的「发送原文件」，再点发送。原文件仍受单文件大小限制。
- **成员邀请过期。** 用「邀请新朋友」重新生成链接。**首次服主激活链接过期**且服主尚未激活时，重启 API 后重新在服务器终端读取链接。[服主激活与恢复说明](DEPLOY.md#2-配置并启动)
